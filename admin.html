Configurar el panel

Solo se hace una vez. El panel guarda las noticias directamente en GitHub, así que necesita una llave de acceso limitada a este repositorio. La llave se guarda cifrada con la contraseña que elijas.

  1. Abre github.com/settings/personal-access-tokens/new.
  2. Ponle un nombre, por ejemplo «Panel de noticias», y una caducidad (máximo 1 año).
  3. En Repository access elige Only select repositories y marca .
  4. En Permissions → Repository permissions, pon Contents en Read and write.
  5. Pulsa Generate token, copia la llave y pégala aquí.
La llave cifrada se guarda en el repositorio público. Con una contraseña larga (una frase de varias palabras) nadie puede descifrarla. Si la olvidas, crea una llave nueva y vuelve a configurar el panel.

Entrar

Escribe la contraseña del panel para añadir y editar noticias.

Cambiar contraseña

La llave de GitHub sigue siendo la misma; solo cambia la contraseña con la que se protege. Si quieres usar una llave nueva, pégala también.
